# Transcribe CLI help

This document is the canonical source for user-facing help generated by the
`transcribe` executable. Level-two heading identifiers are consumed by the
Swift application and must remain unique.

## root.abstract

Transcribe audio and video into summaries, transcripts, subtitles, or timestamped JSON.

## root.discussion

Subcommands:
  summarize  Create a transcript and LLM-powered meeting summary.
  text       Create a plain-text, Markdown, or document transcript.
  srt        Create SRT subtitles.
  vtt        Create WebVTT subtitles.
  words      Create full JSON containing token-level timestamps.

Word timestamp JSON:
  transcribe words INPUT --output OUTPUT.json

The words command writes JSON to the output file, not to standard output.
Progress messages are printed separately. Timestamp data is stored at
transcription[].tokens[].timestamps. Whisper tokens can be whole words,
punctuation, or word fragments.

Config file: ~/.config/transcribe-summarize/config.yaml

All subcommands support --speakers for speaker diarization.
Run transcribe help SUBCOMMAND for command-specific options.

## common.input-file

Path to the audio or video file to transcribe.

## common.output

Output path. The default uses the input basename and command-specific extension.

## common.model

Whisper model name. Known models are tiny, base, small, medium, and large; the default is small. Custom GGML model names are also accepted.

## common.speakers

Speaker names as a comma-separated list or path to a names file.

## common.preprocess

Audio preprocessing mode: auto, none, or analyse. The default is auto.

## common.device

Diarization compute device: auto, cpu, mps, or cuda. The default is auto.

## common.verbose

Increase logging verbosity. Repeat the option for more detail.

## summarize.abstract

Transcribe audio and generate an LLM-powered meeting summary.

## summarize.discussion

Runs the full pipeline: audio extraction, whisper.cpp transcription, optional
speaker diarization, LLM summarization, and document output.

With --llm auto, provider priority defaults to ollama, claude, then openai.
The llm_priority config setting changes that order.

## summarize.format

Output format: md, docx, odt, pdf, or html. The default is md.

## summarize.timestamps

Include timestamps. Enabled by default.

## summarize.confidence

Minimum confidence threshold from 0.0 to 1.0. The default is 0.8.

## summarize.llm

LLM provider: claude, openai, ollama, or auto. The default is auto.

## summarize.dry-run

Show configuration and intended processing without transcribing.

## text.abstract

Generate a plain-text, Markdown, or converted document transcript.

## text.format

Output format: txt, md, docx, odt, pdf, or html. The default is txt.

## text.timestamps

Include segment timestamps. Disabled by default.

## srt.abstract

Generate SRT subtitles from audio or video.

## subtitle.max-len

Maximum subtitle line length in characters. The default is 48; zero is unlimited.

## subtitle.split-on-word

Split subtitles at word boundaries when applying the maximum line length. Enabled by default.

## vtt.abstract

Generate WebVTT subtitles from audio or video.

## words.abstract

Generate full whisper.cpp JSON with timestamped token data.
